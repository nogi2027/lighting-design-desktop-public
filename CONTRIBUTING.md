# Contributing

Keep the app offline and single-user. Use small changes, preserve script anchor
coordinates, and keep existing cue numbers unless the user changes them.
Every persisted format change needs version handling and a round-trip test.
Do not add real production scripts, personal show files, or credentials to tests.

Run typecheck, lint, unit tests, build, and desktop tests before a pull request.
Include a screenshot for visual changes and describe tested operating systems.
Contributions must be compatible with MIT licensing; retain third-party notices.
